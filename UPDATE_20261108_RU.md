# Обновление GOOM: чешский/английский и фирменные аккаунты

## Публикация

1. В Firebase Console → Authentication → Sign-in method включите **Email/Password**. Провайдер Google также должен оставаться включённым.
2. Опубликуйте новые правила из этого архива:

   ```powershell
   firebase deploy --project pztsepscctv --only "firestore:rules,storage"
   ```

   Можно также заменить содержимое вкладок Rules в Firestore и Storage соответствующими файлами `firestore.rules` и `storage.rules` из архива и нажать Publish. Для правил Storage нужен доступ к документам Firestore; при первой настройке Firebase может предложить выдать это разрешение.

3. Загрузите **все HTML, JS и PNG** из архива в корень GitHub-репозитория одним коммитом. Включены новые `i18n.js`, `account-profile.js` и обновлённый `Hi.png`. Каталог `BAZE` не является актуальной версией приложения.
4. После публикации сайта нажмите Ctrl+F5.

GitHub обновляет файлы сайта. Правила Firebase публикуются отдельно — второй пункт нужен для новой регистрации и ограничения облака.

## Что изменилось

- Чешский язык по умолчанию, переключатель Čeština / English в приветствии и программе; выбор сохраняется.
- Прозрачный фон `Hi.png`, без рамки приветственного окна. Возврат — стрелка в левом верхнем углу.
- Облачная кнопка убрана из стартового выбора проекта.
- Регистрация и вход по произвольной почте, пароль и восстановление пароля. Google-вход сохранён.
- При регистрации можно выбрать Firma и ввести IČO. Проверяется длина и контрольная цифра IČO; обращения к реестру ARES нет.
- После подтверждения email фирменный аккаунт автоматически получает ключ. В профиле есть кнопка «E-mail jsem ověřil(a)» для завершения этого шага без повторного входа.
- Обычному пользователю кнопка аккаунта показывает сведения и настройки. Фирменному аккаунту с выданным ключом открываются облачные проекты; сведения пользователя доступны из облачного окна.
- Правила Firestore и Storage проверяют фирменный доступ независимо от интерфейса.

Полный ключ виден после выдачи; его можно скопировать. После обновления страницы показывается маска, а при необходимости можно выпустить новый ключ. Ключ привязан к Firebase-аккаунту пользователя.

Проверки: 19 браузерных сценариев и 10 проверок с настоящими SDK и локальными эмуляторами Firebase. Рабочий Firebase-проект при этих проверках не менялся.
