# Удаление пользователей

В админке: Пользователи → ⋯ у нужного пользователя → Удалить пользователя. Для подтверждения введите e-mail выбранного аккаунта. Администратор может удалить обычного пользователя, владелец — также администратора. Собственный аккаунт и аккаунт владельца защищены.

Удаляются вход Firebase Authentication, профиль с вложенными проектами всех четырёх программ, принадлежащие аккаунту файлы Cloud и персональные счётчики активности. Отзывы, история платежей и аудит сохраняются. Аккаунт с действующим оплаченным Stripe-периодом сначала требует урегулирования подписки; кнопка не отменяет платёж автоматически.

Сервер ставит метку удаления до очистки, отзывает вход и закрывает доступ старым сеансам. Ошибку очистки можно повторить из того же окна; операция идемпотентна. Клиент не получает права напрямую удалять профили или роли. Реальные аккаунты при проверке и развёртывании не удаляются.
