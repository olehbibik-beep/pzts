# Импорт чертежей

Все четыре редактора принимают перетаскивание одного файла на страницу. Поддерживаются проекты .TECH / .bips / .cctv, PDF, изображения и DXF. DWG преобразуется локально в отдельном Web Worker в DXF, затем открывается как векторная подложка. Исходный DWG не меняется и не отправляется на сервер. При первом открытии загружается конвертер LibreDWG 0.9.3; нужна сеть для загрузки этой библиотеки.

Поддерживаются 2D-элементы существующего DXF-импортера. 3D-тела, внешние ссылки, фирменные CAD-объекты и встроенные изображения могут не перенестись. Неподдерживаемые типы перечисляются после импорта. Ошибка разбора оставляет текущий проект без изменений.

Расширение XCX само по себе не определяет известный формат CAD. Для таких файлов проверяется содержимое: DWG, DXF или проект GooM. Для другого варианта нужен файл-пример и название исходной программы. Неизвестное содержимое не применяется к проекту.

Службы админки и Team находятся в cloud-functions (codebase project-cloud), отдельно от платёжного модуля. Для них не требуется настраивать Stripe. В админку редактор переходит в той же вкладке, сохраняя сеанс входа.

Индикатор Cloud показывает занятые места: 0/5 — чёрная дуга, каждое сохранение добавляет голубой сегмент. Число свободных мест указано рядом.

SATEL документирует XCX как экспорт конфигурации DLOADX: https://www.satel.eu/ru/download/instrukcje/int-vg_ru_3d30712c.pdf (раздел 8.1.5). Прямой импорт конфигурации SATEL в GooM пока не реализован; этот файл не следует считать CAD-подложкой.
